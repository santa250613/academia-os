# Academia OS — prototipo (Gestión de Innovación)

Demo publicada en https://santa250613.github.io/academia-os/

- `app/index.html` — dashboard (clientes activos, pagos, asistencia, cartera, recordatorios)
- `app/check.html` — ingreso por sticker NFC (nombre + número → asistencia del día)

## Datos del prototipo
Los datos viven en `localStorage` del navegador (demo). Cada equipo puede editar los archivos y hacer push; la página se publica sola (GitHub Pages).
