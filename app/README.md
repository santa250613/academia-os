# Academia OS

🌐 **Demo:** https://santa250613.github.io/academia-os/

**Academia OS** — sistema prototipo para gestión de academias de baile: control de clientes, pagos, asistencia por **sticker NFC** y recordatorios automáticos. Prototipo para la clase de Gestión de Innovación.

- **Dashboard:** `app/index.html` — KPIs, tasa de asistencia, flujo de cartera, tabla de clientes, recordatorios.
- **Ingreso NFC:** `app/check.html` — página que abre sticker NFC: registro con nombre + número y marca de asistencia del día.
